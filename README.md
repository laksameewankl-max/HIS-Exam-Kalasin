# HIS University Hospital - Exam Project (Kalasin)

โปรเจกต์นี้จัดทำขึ้นเพื่อนำเสนอแนวทางการจัดการฐานข้อมูลและการออกแบบ UI/UX สำหรับระบบสารสนเทศโรงพยาบาลมหาวิทยาลัยกาฬสินธุ์ ตามโจทย์ข้อสอบปฏิบัติ

---

## 📊 ส่วนที่ 1: SQL Query สำหรับงานวิจัย
ระบบรองรับการดึงข้อมูลผู้ป่วยกลุ่มโรคเบาหวาน (ICD-10: E11) ที่เข้ารับบริการในช่วงเวลาที่กำหนด เพื่อใช้ในการติดตามผลการรักษาและการวิจัยของโรงพยาบาล

**ไฟล์แนบ:** `database.sql` (รวม Schema, Mock Data และ Query)

## 🎨 ส่วนที่ 2: UI/UX Design - EMR Teaching Dashboard

### แนวคิดการออกแบบ (Design Concept)
หน้าจอ "EMR Teaching Dashboard" ถูกออกแบบมาเพื่อตอบโจทย์สถานะการเป็น "โรงพยาบาลมหาวิทยาลัย" ที่ต้องสมดุลระหว่างประสิทธิภาพในการรักษาและความปลอดภัยของผู้ป่วย กับกระบวนการเรียนการสอนของนักศึกษาแพทย์ โดยยึดหลัก UI/UX ดังนี้:

1.  **Split-Screen Collaboration:** แบ่งพื้นที่หน้าจอหลักเป็น 2 คอลัมน์ขนานกัน เพื่อให้นักศึกษาแพทย์บันทึกประวัติ (ซ้าย) และอาจารย์แพทย์สามารถตรวจสอบ, ให้ความเห็น, และยืนยันการรักษา (ขวา) ได้พร้อมกันในหน้าเดียว ลดการคลิกเปลี่ยนหน้า
2.  **Medication Error Prevention:** ข้อมูล **"การแพ้ยา (Drug Allergy)"** จะถูกแสดงเป็นแถบสีแดงเด่นชัดที่ด้านบนสุดของหน้าจอเสมอ และระบบสั่งยาจะมีฟังก์ชัน "Drug-Drug Interaction Alert" เพื่อแจ้งเตือนทันทีหากสั่งยาที่ขัดกัน
3.  **Efficiency with Order Sets:** สำหรับโรคเรื้อรังเช่นเบาหวาน (E11) ระบบมีปุ่ม "Quick Order Set" สำหรับสั่งยากลุ่มมาตรฐานที่ใช้บ่อย เพื่อความรวดเร็วและลดโอกาสการพิมพ์ชื่อยาผิด
