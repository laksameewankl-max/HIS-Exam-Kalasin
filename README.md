## ส่วนที่ 2: UI/UX Design - EMR Teaching Dashboard

### 🏥 แนวคิดการออกแบบ (Design Concept)
ออกแบบโดยใช้หลัก **"Shared Workspace"** เพื่อลดความซับซ้อนในการใช้งานจริง:
- **Minimize Clicks:** รวมข้อมูล Patient Profile, บันทึกการตรวจ และคำสั่งรักษาไว้ในหน้าเดียว ไม่ต้องสลับหน้าจอไปมา
- **Medication Error Prevention:** มีแถบแจ้งเตือนการแพ้ยา (Allergy) สีแดงเด่นชัด และระบบตรวจสอบคำสั่งยาก่อนยืนยัน (Double Check)
- **Roles Separation:** แยกพื้นที่บันทึกระหว่าง "นักศึกษา" และ "อาจารย์" ชัดเจน แต่แสดงผลคู่กันเพื่อให้ง่ายต่อการสอนและตรวจสอบ (Feedback)

### 📋 โครงสร้างหน้าจอ (Wireframe)
- **บน:** Patient Profile (HN, ชื่อ-สกุล) + ข้อมูลแพ้ยา (Allergy Alert)
- **กลางซ้าย:** ประวัติโรคประจำตัวเดิม และผลตรวจทางห้องปฏิบัติการ
- **กลางขวา:** หน้าต่างคู่ (Split View) 
    - ฝั่งนักศึกษา: บันทึกอาการและการตรวจร่างกาย
    - ฝั่งอาจารย์: วินิจฉัยและสั่งการรักษา
- **ล่าง:** ปุ่ม Confirm Order (ซึ่งนักศึกษาจะกดไม่ได้ ต้องเป็นอาจารย์เท่านั้น)
